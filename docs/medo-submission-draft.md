## Recommended MeDo-native project

Project title:
Hackathon Submission Checklist Builder

Category:
Work & Productivity

Tagline:
A no-code MeDo app that turns a hackathon URL and builder profile into a submission checklist, eligibility checklist, and payout-risk review.

Core screens / flows to build in MeDo:
1. Intake form
   - Hackathon URL
   - Deadline
   - Residence / nationality
   - Prize payout rails
   - Required deliverables

2. Risk checklist
   - Residence eligibility
   - Nationality/citizenship restrictions
   - Sanctions/OFAC exclusions
   - Payout method: bank / PayPal / Web3 / hardware / credits
   - Terms/final-submit boundary

3. Submission asset generator
   - Short project description
   - Long description
   - Demo video outline
   - Public repo/demo URL checklist
   - Organizer questions to confirm payout compatibility

4. Final review dashboard
   - Ready / blocked / needs user authorization
   - Links to docs and submission assets

Why it fits MeDo:
- No-code productivity dashboard is natural for MeDo.
- It complements the existing scout-agent repo without needing MeDo to rebuild the full Node app.
- It demonstrates practical AI/no-code app generation and workflow automation.

## Draft Devpost copy

Short description:
Hackathon Submission Checklist Builder helps solo builders avoid last-minute disqualification. It collects a hackathon URL, builder profile, deliverables, and payout constraints, then turns them into a clear readiness checklist covering eligibility, payout risk, demo assets, and human approval boundaries.

How MeDo was used:
MeDo was used to generate the working application UI, data-entry flow, checklist dashboard, and iteration workflow from natural-language prompts. The app focuses on turning ambiguous hackathon requirements into a concrete, reviewable action list.

Problem solved:
Hackathon builders often discover eligibility, demo, payout, or terms blockers too late. The app surfaces these blockers early and separates safe automation from actions that require the human to accept rules, sign in, or submit.
